# Task Management System

## About the Project
The Task Management System is a simple web-based application developed to help users enter, display, and clear task text. It demonstrates the basic concepts of frontend web development using HTML, CSS, and JavaScript.

## Features
- Enter task text through an input field.
- Display the entered text.
- Clear the displayed text.
- Apply basic text formatting using additional buttons.
- Simple and user-friendly interface.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
- `index.html` – Defines the structure of the web page.
- `style.css` – Provides styling for the application.
- `app.js` – Implements the application's interactive functionality.

## How to Use
1. Open the application in a web browser.
2. Enter text in the task input field.
3. Click **Show Task** to display the text.
4. Click **Clear** to clear the displayed text.

## Learning Outcomes
- Understanding HTML page structure.
- Applying CSS for styling.
- Using JavaScript functions and DOM manipulation.
- Handling user interactions through buttons.

## Future Improvements
- Add multiple tasks to a task list.
- Allow users to mark tasks as completed.
- Add task deletion and editing.
- Store tasks using browser local storage.
- Add task priorities and deadlines.
